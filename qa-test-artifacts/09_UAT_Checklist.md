# UAT Checklist

## Scenario 1: Requester Submits Request
- [ ] Requester can open form.
- [ ] Requester can enter valid details.
- [ ] Requester can submit request.
- [ ] Status becomes Pending Approval.

## Scenario 2: Approver Reviews Request
- [ ] Approver can view pending request.
- [ ] Approver can approve request.
- [ ] Approver can reject with reason.
- [ ] Status updates correctly.

## Scenario 3: Business Rules
- [ ] Requester cannot approve own request.
- [ ] Approved request is read-only.
- [ ] Rejection requires reason.
- [ ] History records key actions.
