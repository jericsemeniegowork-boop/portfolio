# Regression Checklist

## Login and Access
- [ ] Requester can login.
- [ ] Approver can login.
- [ ] Unauthorized user cannot access approval action.

## Request Creation
- [ ] Create request page opens.
- [ ] Valid draft can be saved.
- [ ] Required field validation works.
- [ ] Invalid amount values are blocked.

## Approval Workflow
- [ ] Request can be submitted.
- [ ] Approver can approve.
- [ ] Approver can reject with reason.
- [ ] Rejection without reason is blocked.

## Status and History
- [ ] Request list shows latest status.
- [ ] Detail page shows same status.
- [ ] History records create, submit, approve, and reject actions.
