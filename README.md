## Case Study Workflow

The sample workflow covers:

```text
Requester creates a purchase request
→ Requester submits it for approval
→ Approver approves or rejects the request
→ System updates the request status
→ Request history/audit trail is recorded
→ Approved requests become read-only
→ Regression checks confirm related workflows still work
```

## QA Artifacts Included

The `qa-test-artifacts/` folder includes:

| Artifact | Purpose |
|---|---|
| Requirement Analysis | Identifies testable requirements, assumptions, risks, and clarification questions |
| Test Plan | Defines scope, test types, entry/exit criteria, environment, and tools |
| Test Scenarios | Lists high-level workflows and conditions to validate |
| Manual Test Cases | Provides detailed steps, test data, and expected results |
| Requirement Traceability Matrix | Maps requirements to test scenarios and test cases |
| Test Data | Includes valid, invalid, boundary, and role-based data |
| Defect Report Samples | Shows clear bug reporting with steps, expected vs actual results, severity, and priority |
| Regression Checklist | Covers impacted areas after fixes or releases |
| UAT Checklist | Supports business-user validation and sign-off |
| Test Execution Report | Tracks pass, fail, blocked, and defect status |
| Test Summary Report | Summarizes testing results, risks, and release recommendation |
| Release Validation Checklist | Supports pre-release and post-release checks |
