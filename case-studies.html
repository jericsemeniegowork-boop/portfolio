Internal Service Filing Workflow

Manual test coverage was prepared for an internal service filing workflow. The scope covered UI behavior, navigation, form validation, record management, data integrity, end-to-end filing, document generation, and Jira issue tracking.

Testing Scope

  • Repository and list page behavior
  • Add new filing entry and form validation
  • View and verify record details
  • Edit and update status and remarks
  • Generate or download related forms
  • Data consistency across all views

What This Demonstrates

  • Test coverage planned and structured before execution
  • Test cases grouped and organized by testing area
  • Positive, negative, and end-to-end scenarios covered
  • Failed test results connected to Jira defect reporting

Defect Sample

Cleaned and anonymized defect demonstrating documentation style.

Back Button Navigation Redirects to Incorrect Page

Medium Severity
ModuleTime Management Workflow — Navigation
SeverityMedium
PriorityHigh
DescriptionDuring testing of a time management workflow, the Back button was observed to inconsistently return users to the most recent page or panel previously accessed. The issue appeared across multiple screens, suggesting a possible shared navigation handling concern.
Steps1. Open the time management module.
2. Navigate to a sub-panel or detail page.
3. Click the Back button.
4. Observe the page the system navigates to.
ExpectedSystem navigates to the most recently accessed page or panel.
ActualSystem navigates to an incorrect page, skipping the previous panel.
ImpactDisrupts user navigation flow; increases task completion time and may lead to data loss if users navigate away unintentionally.
