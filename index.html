QA Process

A practical manual testing workflow used across the portfolio case studies.

1

Requirement Analysis

Review requirements, clarify scope, identify risks.

2

Test Planning

Define scope, environment, entry and exit criteria.

3

Test Design

Create scenarios, test cases, expected results, and RTM.

4

Test Data

Prepare valid, invalid, boundary, and role-based data.

5

Environment Check

Confirm QA/staging readiness through smoke checks.

6

Execution

Run test cases and record actual results.

7

Defect Management

Log issues with steps, expected vs actual, severity, priority, and evidence.

8

Retesting

Retest fixed defects using original reproduction steps.

9

Regression

Confirm existing features still work after changes.

10

Reporting

Summarize results, defects, risks, and release recommendation.
